Deep Learning as Function Composition
From Neurons and Functions to CNN, ResNet, Attention, and Vision Transformers
Tutorial for undergraduate students
T óm tắt nội dung
This tutorial develops a mathematical and programming-oriented understanding of con-
volutional neural networks (CNNs). Instead of memorizing architectures, students learn to
interpret deep learning as the composition of functions. The tutorial starts from a neuron and
linear function, introduces nonlinear activation functions, explains layers and composition,
and then derives the main operations of CNNs: convolution, stride, pooling, normalization,
flattening, and classification. The tutorial then explains the evolution from LeNet and AlexNet
to VGG, Inception, ResNet, DenseNet, U-Net, MobileNet, EfficientNet, attention-based CNNs,
and Vision Transformers. Each major idea is connected to executable Python/PyTorch code.

2 The Mathematical Starting Point: A Function
Before studying neural networks, consider an ordinary function
f : Rd → Rm.
For example,
f (x) = 2 x + 1.
If x = 3, then
f (3) = 7 .
A neural network is also a function. The difference is that the function is not manually specified.
Its parameters are learned from data.
For a parameterized function,
fθ(x),
the parameter vector θ is learned during training.
Thus the learning problem can be written as
Find θ such that fθ(x) produces useful outputs.

4 Why Activation Functions Are Necessary
Suppose we compose two linear functions:
f1(x) = a1x + b1
and
f2(x) = a2x + b2.
Then
f2(f1(x)) = a2(a1x + b1) + b2.
Therefore,
f2(f1(x)) = ( a2a1)x + (a2b1 + b2),
which is still linear-affine.
Consequently,
Linear ◦ Linear = Linear.
A deep network containing only linear layers would not obtain the expressive power expected
from deep learning.
We therefore introduce a nonlinear function
h = σ(z).

46 A Practical Mental Model
When encountering any CNN architecture, ask:
1. What is the input representation?
2. What local operation is being learned?
3. Where is nonlinearity introduced?
4. How does spatial resolution change?
5. How does the number of channels change?
6. Is information added, discarded, or reused?
7. Are there shortcut paths?
8. Are some features weighted more strongly?
9. Are interactions local or global?
10. What limitation of an earlier architecture is being addressed?
These ten questions are more useful than memorizing the names of dozens of architectures.
