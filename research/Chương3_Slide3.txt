What Is a Neural Network?
A neural network is a parameterized function composed of successive
transformations.
A simple network can be written as
fθ(x) = W2 ϕ(W1x + b1) + b2.
The network contains:
weights W ;
biases b;
activation functions ϕ;
learnable parameters θ.
Key Idea
A neural network is not magic.
It is a parameterized mathematical function whose parameters are learned
from data.

Why Do We Need Activation Functions?
Suppose every layer were purely linear:
h1 = W1x + b1
and
h2 = W2h1 + b2.
Then the composition is still a linear-affine transformation:
h2 = W2W1x + W2b1 + b2.
Therefore, stacking linear layers alone does not provide the expressive
power expected from a deep network.
Depth + Nonlinearity → Expressive Model

Why Mini-Batches?
Instead of processing all N observations simultaneously, training can use
mini-batches.
X → X1, X2, . . . ,XB .
For each batch:
Lb = L(Xb, yb).
Advantages include:
efficient memory usage;
efficient computation;
frequent parameter updates;
compatibility with GPU computation.

Training vs. Evaluation Mode
PyTorch models have different operating modes.
During training:
model . train ()
During validation or testing:
model . eval ()
During evaluation, gradients are normally not required:
model . eval ()
with torch . no_grad () :
outputs = model ( X_test )
Important Distinction
model.train() and model.eval() control the model’s operating mode.
torch.no grad() disables gradient computation for the enclosed
operations.
